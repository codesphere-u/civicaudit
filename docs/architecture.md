# Architecture — `civicaudit`

- `civicaudit.forensics`: Pure-Python OCDS 1.1 release parser, rolling-window contract-splitting detector, bipartite bidder-tender Jaccard collusion graph analyzer, Benford's Law MAD & Chi-Squared engine, and structured `AuditReport` models.
- `civicaudit.cli`: JSON/Markdown evidence report generator and offline CLI (`audit`, `demo`).
